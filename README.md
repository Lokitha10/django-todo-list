# 📝 Django To-Do List Application

A simple and user-friendly **To-Do List Web Application** built using **Django**, **Python**, **HTML**, **CSS**, and **SQLite**. This application allows users to manage their daily tasks efficiently by adding, updating, and deleting tasks.

---

## 🚀 Live Demo

🌐 **Live Website:**  
https://django-todo-list-i4gf.onrender.com/

📂 **GitHub Repository:**  
https://github.com/Lokitha10/django-todo-list

# 📌 Features

- ✅ Add New Tasks
- ✏️ Edit Existing Tasks
- 🗑️ Delete Tasks
- 📋 View All Tasks
- 📌 Task Status (Pending / Completed)
- 🎨 Simple and Responsive User Interface
- 💾 SQLite Database Integration
- ☁️ Deployed on Render

# ⚙️ Installation

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/Lokitha10/django-todo-list.git
```

---

## 2️⃣ Move into the Project Folder

```bash
cd django-todo-list
```

---

## 3️⃣ Create Virtual Environment

Windows

```bash
python -m venv venv
venv\Scripts\activate
```

Linux / Mac

```bash
python3 -m venv venv
source venv/bin/activate
```

---

## 4️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 5️⃣ Apply Migrations

```bash
python manage.py migrate
```

---

## 6️⃣ Run the Development Server

```bash
python manage.py runserver
```

Open your browser and visit

```
http://127.0.0.1:8000/
```

# 📋 Usage

1. Open the application.
2. Click **Add New Task**.
3. Enter Task Title.
4. Enter Task Description.
5. Select Task Status.
6. Click **Save Task**.
7. Edit or Delete tasks whenever required.
