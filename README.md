# Django To-Do List

A simple To-Do List web application built using Django. Users can add, edit, update, and delete tasks.

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark task status (Pending / Completed)
- Simple and clean UI
- SQLite Database

## Technologies Used

- Python
- Django
- HTML
- CSS
- SQLite
- Render

## Installation

```bash
git clone https://github.com/Lokitha10/django-todo-list.git
cd django-todo-list
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Open:

```
http://127.0.0.1:8000/
```
